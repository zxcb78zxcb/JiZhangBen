# 记账本 · Kakeibo

纯前端家计簿。周为小周期、月为小总期、年为总单位量。
无后端、无依赖，数据保存在浏览器 localStorage。

## 用法

- 直接在浏览器打开 `index.html`
- 或部署到 GitHub Pages：Settings → Pages → Branch `main` / `(root)`

## 功能

- 11 个项目：吃饭费用（买菜/外食/烟酒）、日用品、美容、衣服（普通衣服/服饰杂货）、
  兴趣娱乐、交际费用、教育、交通、医疗、其他费用、收入
- 每项两列（项目名称 + 金额），金额栏按 **回车** 自动加一行
- 金额栏支持算式（`380+520`、`100×3`、`1,200+800`），实时预览结果，回车 / 失焦自动填入
- 支出黑字、收入蓝字
- 日 / 周 / 月 / 年四级自动合计
- 每日备注，月度固定支出（房租·通信费·水电费·会费·税费）
- 月度各项与上月对比（增减额 + 百分比）+ 分析笔记
- JSON 备份导入导出、CSV 明细导出
- **多设备自动同步**：局域网（自带 Python 服务端）或 GitHub Gist 云同步

## 同步与离线

带时间戳的合并，粒度到**「某一天的某个分类」**——同一天里 A 设备记交通、B 设备记买菜
可以共存，只有同一天同一分类的冲突才取修改时间晚的一方。删除用墓碑标记避免被旧副本复活。
`mergeDB()` 满足交换律与幂等，多设备任意顺序同步都收敛到同一结果。
同一套规则在服务端 `server.py: merge()` 另有一份 Python 实现，测试校验两边逐字节一致。

`sw.js` + `manifest.webmanifest` 提供 PWA 离线能力：装到主屏后完全无网也能记账，
本地先存，联网自动补传（`navigator.onLine` + `online` 事件 + 指数退避重试）。

GitHub Pages 版可直接使用 Gist 云同步，令牌只存于浏览器 localStorage，
不会写入导出的备份文件。
